## 📝 Passo a Passo: Como adicionar o seu site aqui?

Para incluir o seu projeto na tabela, siga estas instruções simples:

### 1️⃣ Faça um Fork do Repositório
Clique no botão **`Fork`** (no canto superior direito desta página) para criar uma cópia deste repositório na sua conta do GitHub.

### 2️⃣ Clone o repositório na sua máquina
